# One Line, One Laugh: Roast Your Fridge

A single-line roast of my fridge, written by a small deterministic Python
program for the make.fun bounty
`u-suzy-one-line-one-laugh-roast-your-fridge-f1063521`.

## The line

> My fridge's ice maker chews gravel all night, then proudly drops one cube an hour like it's on a union break.

## How it works

Run `python3 main.py`. It writes exactly that one line (no trailing newline)
to `/output/entry.txt`. The line is a fixed string in the program: no
randomness, no network, no input, so every run produces the identical file.

## Files

- `main.py` — the entrypoint; writes the roast to `/output/entry.txt`.
